# Third-party references

Save the Battery's current implementation is original code under the MIT license. It has no bundled third-party packages. Apple platform SDKs are linked as system frameworks.

The following upstream projects were researched, but their source code or binaries are not bundled:

- [Stats](https://github.com/exelban/stats): reference for IORegistry battery field names and the AppleSmartBatteryPack temperature location.
- [batt](https://github.com/charlie0129/batt): firmware compatibility and adapter-mode limitations.
- [OpenDente](https://github.com/killerk3emstar/OpenDente): capability and model support research.

No AlDente artwork or code is included. Future code reuse requires an explicit license and attribution review before inclusion.
