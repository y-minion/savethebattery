# VibeBattery 0.2.0 (beta)

First public release. It is a beta: expect rough edges, and please report them as GitHub issues.

## Requirements
- macOS 15 or later, Apple silicon or Intel (universal build).
- The charge limit needs Apple silicon and macOS 26.4 or later. Everything else works on macOS 15 and up.
- The app is signed with a free Apple Development certificate and is not notarized. The install command below avoids the Gatekeeper prompt; if you download the zip in a browser, open the app once, then go to System Settings › Privacy & Security and click Open Anyway next to VibeBattery.
- Limits below 80%, the Low Power Mode switch and the MagSafe LED need an optional helper, which you install from the app with the macOS administrator-password dialog.

## Install
```
curl -fsSL https://github.com/y-minion/vibebattery/releases/latest/download/install.sh | sh
```
The installer checks the SHA-256 of the download and installs to /Applications without sudo.

## Uninstall
```
curl -fsSL https://github.com/y-minion/vibebattery/releases/latest/download/uninstall.sh | sh
```

## Upgrading from an earlier build
If you installed the helper before, install it again from the app. The helper protocol changed to version 3; an older helper still sets limits, but the app will ask you to reinstall it.

# VibeBattery 0.2.0 (베타)

첫 공개 버전입니다. 베타이므로 거친 부분이 있을 수 있습니다. 문제는 GitHub 이슈로 알려 주세요.

## 요구 사항
- macOS 15 이상, Apple 실리콘 또는 Intel (유니버설 빌드).
- 충전 상한은 Apple 실리콘과 macOS 26.4 이상에서만 지원합니다. 나머지 기능은 macOS 15 이상에서 동작합니다.
- 앱은 무료 Apple Development 인증서로 서명했으며 공증(notarization)은 받지 않았습니다. 아래 설치 명령은 Gatekeeper 경고 없이 설치합니다. 브라우저로 zip을 받았다면 앱을 한 번 연 뒤, 시스템 설정 › 개인정보 보호 및 보안에서 VibeBattery 옆의 그래도 열기를 누르세요.
- 80% 미만 상한, 저전력 모드 스위치, MagSafe LED에는 선택 설치 헬퍼가 필요합니다. 헬퍼는 앱에서 macOS 관리자 암호 창을 거쳐 설치합니다.

## 설치
```
curl -fsSL https://github.com/y-minion/vibebattery/releases/latest/download/install.sh | sh
```
설치 프로그램은 내려받은 파일의 SHA-256을 확인하고, sudo 없이 /Applications에 설치합니다.

## 제거
```
curl -fsSL https://github.com/y-minion/vibebattery/releases/latest/download/uninstall.sh | sh
```

## 이전 빌드에서 업그레이드
이전에 헬퍼를 설치했다면 앱에서 다시 설치하세요. 헬퍼 프로토콜이 3으로 바뀌었습니다. 이전 헬퍼도 상한은 설정하지만 앱이 재설치를 안내합니다.
