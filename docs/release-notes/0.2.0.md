# Save the Battery 0.2.0 (beta)

First public release. It is a beta: expect rough edges, and please report them as GitHub issues.

## Requirements
- macOS 15 or later, Apple silicon or Intel (universal build).
- The charge limit needs Apple silicon and macOS 26.4 or later. On an Apple silicon Mac with an older macOS, update macOS to turn it on; Intel Macs are not supported. Everything else works on macOS 15 and up.
- The app is signed with a free Apple Development certificate and is not notarized. The install command below avoids the Gatekeeper prompt. If you download `savethebattery.dmg` in a browser, drag the app to Applications, open it once, then go to System Settings › Privacy & Security and click Open Anyway next to Save the Battery.
- Limits below 80%, the Low Power Mode switch and the MagSafe LED need an optional helper. The app installs it with the macOS administrator-password dialog the first time you use one of them.

## New in this release
- The app is now called Save the Battery, with a new icon. The command-line tool is `stb`.
- On first launch the app offers to set an 80% limit, and offers to move itself into Applications if it runs from anywhere else.
- Later versions install from inside the app: Settings › Updates › Update now. It checks the checksum and the team signature before it replaces anything.
- A disk image (`savethebattery.dmg`) for browser downloads.

## Install
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/install.sh | sh
```
The installer checks the SHA-256 of the download and installs to /Applications without sudo.

## Uninstall
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/uninstall.sh | sh
```

## Upgrading from an earlier build
If you installed the helper before, install it again from the app. The helper protocol changed to version 3; an older helper still sets limits, but the app will ask you to reinstall it.

# Save the Battery 0.2.0 (베타)

첫 공개 버전입니다. 베타이므로 거친 부분이 있을 수 있습니다. 문제는 GitHub 이슈로 알려 주세요.

## 요구 사항
- macOS 15 이상, Apple 실리콘 또는 Intel (유니버설 빌드).
- 충전 상한은 Apple 실리콘과 macOS 26.4 이상에서만 지원합니다. 이전 macOS를 쓰는 Apple 실리콘 맥은 macOS를 업데이트하면 쓸 수 있고, Intel 맥은 지원하지 않습니다. 나머지 기능은 macOS 15 이상에서 동작합니다.
- 앱은 무료 Apple Development 인증서로 서명했으며 공증(notarization)은 받지 않았습니다. 아래 설치 명령은 Gatekeeper 경고 없이 설치합니다. 브라우저로 `savethebattery.dmg`를 받았다면 앱을 응용 프로그램 폴더로 끌어 놓고 한 번 연 뒤, 시스템 설정 › 개인정보 보호 및 보안에서 Save the Battery 옆의 그래도 열기를 누르세요.
- 80% 미만 상한, 저전력 모드 스위치, MagSafe LED에는 선택 설치 헬퍼가 필요합니다. 이 기능을 처음 쓸 때 앱이 macOS 관리자 암호 창으로 설치합니다.

## 이번 버전에서 새로워진 점
- 이름이 Save the Battery로 바뀌고 새 아이콘이 생겼습니다. 명령줄 도구는 `stb`입니다.
- 처음 실행하면 80% 상한 설정을 제안하고, 응용 프로그램 폴더 밖에서 실행하면 스스로 옮기겠다고 제안합니다.
- 다음 버전부터는 앱 안에서 설치합니다: 설정 › 업데이트 › 지금 업데이트. 교체하기 전에 체크섬과 팀 서명을 확인합니다.
- 브라우저 다운로드용 디스크 이미지(`savethebattery.dmg`)를 제공합니다.

## 설치
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/install.sh | sh
```
설치 프로그램은 내려받은 파일의 SHA-256을 확인하고, sudo 없이 /Applications에 설치합니다.

## 제거
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/uninstall.sh | sh
```

## 이전 빌드에서 업그레이드
이전에 헬퍼를 설치했다면 앱에서 다시 설치하세요. 헬퍼 프로토콜이 3으로 바뀌었습니다. 이전 헬퍼도 상한은 설정하지만 앱이 재설치를 안내합니다.
