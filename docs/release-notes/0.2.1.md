# Save the Battery 0.2.1

Small fixes after the first release.

- The Korean dashboard title now reads "배터리 현황".
- Every tab opens scrolled to the top instead of keeping the previous tab's position.
- After an in-app update, the new version no longer inherits test settings from the old one.

## Update
In the app: Settings › Updates › Update now. Or run the install command again:
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/install.sh | sh
```
