# Save the Battery 0.2.2

The app icon now shows in Finder and the Dock after an install or update.

- An earlier copy without the icon could leave macOS showing the generic app icon, because every build carried the same build number and date. Each version now has its own build number, and the build, the install command, Move to Applications and Update now all give the app a new date and register it with macOS.

## Update
In the app: Settings › Updates › Update now. Or run the install command again:
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/install.sh | sh
```
If the Dock still shows the generic icon after updating, quit the app and open it again.

# Save the Battery 0.2.2

설치나 업데이트 뒤 Finder와 Dock에 앱 아이콘이 제대로 보입니다.

- 모든 빌드의 빌드 번호와 날짜가 같아서, 아이콘이 없던 이전 사본이 있었다면 macOS가 기본 앱 아이콘을 계속 보여 줄 수 있었습니다. 이제 버전마다 빌드 번호가 다르고, 빌드·설치 명령·응용 프로그램으로 옮기기·지금 업데이트 모두 앱에 새 날짜를 주고 macOS에 다시 등록합니다.

## 업데이트
앱에서: 설정 › 업데이트 › 지금 업데이트. 또는 설치 명령을 다시 실행하세요:
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/install.sh | sh
```
업데이트 뒤에도 Dock에 기본 아이콘이 보이면 앱을 종료했다가 다시 여세요.
