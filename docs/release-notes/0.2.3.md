# Save the Battery 0.2.3

Clearer power and battery state at a glance.

- **Power flow as a picture.** Charger, Mac and battery sit in a row, with dots moving where power flows and a dashed line where nothing does. It shows the watts at each, and the battery's charge, use or hold. It is the second card on the dashboard now, right under the battery.
- **Battery in use while plugged in.** Above the charge limit, macOS runs the Mac from the battery until it is back at the limit. The power flow now says so instead of showing "Charger 0 W".
- **Menu bar.** Each state has its own image and word: ⚡ Charging, 🔌 Holding, 🔋 On battery and 🌡 Heat hold, next to the percent. The image is drawn at menu bar size instead of inside a small battery. If the menu bar is crowded, turn off the word in Settings › Menu bar.

## Update
In the app: Settings › Updates › Update now. Or run the install command again:
```
curl -fsSL https://github.com/y-minion/savethebattery/releases/latest/download/install.sh | sh
```

# Save the Battery 0.2.3

전력과 배터리 상태를 한눈에 더 잘 보이게 했습니다.

- **그림으로 보는 전력 흐름.** 충전기·Mac·배터리를 한 줄로 놓고, 전기가 흐르는 선에는 점이 움직이고 흐르지 않는 선은 점선으로 보입니다. 각 와트와 배터리의 충전·사용·유지를 표시합니다. 대시보드에서는 배터리 카드 바로 아래로 올렸습니다.
- **충전기를 꽂았는데 배터리를 쓸 때.** 배터리가 충전 상한보다 높으면 macOS가 상한까지 배터리로 Mac을 돌립니다. 이제 "충전기 0 W" 대신 그 이유를 알려 줍니다.
- **메뉴 막대.** 상태마다 그림과 글자를 잔량 옆에 보여 줍니다: ⚡ 충전 중, 🔌 유지, 🔋 사용 중, 🌡 과열 보류. 작은 배터리 안이 아니라 메뉴 막대 크기로 그립니다. 메뉴 막대가 붐비면 설정 › 메뉴 막대에서 상태 글자를 끌 수 있습니다.
